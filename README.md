# زبانچه — نسخه‌ی آزمایشی رایگان

آموزش زبان انگلیسی با داستان‌های کارتونی.

این نسخه شامل این بخش‌هاست:
- سطح کودکان «پیپ و بوبو» (۲۰ قسمت)
- سطح A1 «ساختمان شماره‌ی ۴» (۳۰ قسمت)
- آزمون جامع هر دو سطح

## نصب
- **اندروید (Chrome):** صفحه‌ی اپ را باز کن ← منوی ⋮ ← «Install app» یا «افزودن به صفحه‌ی اصلی».
- **آیفون (Safari):** صفحه‌ی اپ را باز کن ← دکمه‌ی اشتراک‌گذاری ← «Add to Home Screen».

بعد از اولین باز شدن با اینترنت، همه‌ی صداها دانلود می‌شوند و اپ بدون اینترنت هم کار می‌کند.

پیشرفتت روی همان گوشی و همان مرورگر ذخیره می‌شود.

صداها با Kokoro ساخته شده‌اند (Apache 2.0). فونت‌ها: Vazirmatn، Lalezar، Nunito، Baloo Bhaijaan 2، Noto Naskh Arabic و Markazi Text (OFL).
